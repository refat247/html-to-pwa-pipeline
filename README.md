# HTML-to-PWA Pipeline

Standalone, public-safe Agent Skill for auditing and converting eligible static HTML projects into installable Progressive Web Apps.

**Status:** Repository bootstrap only. The implementation is under review in a separate Pull Request. No production release, deployment or installation has been approved.

The project follows [Version Manager governance](https://github.com/refat247/medical-cdss-skills/tree/main/version-manager): intentional SemVer, version-declaration verification, CI, evidence-based audits and owner-controlled merges.

No user-specific data, credentials, private JSON or clinical content belongs in this repository.
